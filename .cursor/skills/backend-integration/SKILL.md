# バックエンド連携・認証

## API連携

- APIとの通信は、基本的に`fetch`を使用して行う
- APIエンドポイントは環境変数で管理し、コード内にハードコードしない
- APIレスポンスの型はTypeScriptの型定義を使用して明示的に定義する
- エラーハンドリングは適切に行い、ユーザーにわかりやすいエラーメッセージを表示する
- API呼び出しは、必要に応じてカスタムフックを作成して管理する

## データ管理

- クライアントサイドの状態管理は、必要に応じてReactの`useState`や`useReducer`を使用する
- グローバルな状態管理が必要な場合は、Zustandなどの軽量な状態管理ライブラリを使用する
- サーバーから取得したデータは、可能な限りキャッシュを利用して効率的に管理する
- データの永続化が必要な場合は、IndexedDBを使用してクライアントサイドに保存する
- データの整合性を保つために、APIからのレスポンスを適切にバリデーションする（例: Zodを使用）
- 青空文庫の書籍一覧データは固定のJSONファイルとして管理し、必要に応じて更新する形で運用する
- 青空文庫の書籍データは、サーバーサイドコンポーネントで取得し、クライアントに渡す形で管理する
- 書籍のダウンロード機能は、APIを介して行い、ダウンロードした書籍データはIndexedDBに保存する
- 書籍の閲覧履歴やお気に入り機能などのユーザーデータもIndexedDBに保存し、必要に応じてAPIと同期する形で管理する
