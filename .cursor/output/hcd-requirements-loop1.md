# HCD ループ1 ユーザー要求事項

UXゴール: 読みたい作品をスムーズに検索できて閲覧できること。軽快に動作すること。

## Phase1で観測した事実
- TOP初回表示: 約2.7s
- 検索入力→API応答: 約3.9s（うち debounce 300ms）
- `/api/works?q=夏目漱石` 単体: 初回 3.4s / 2回目 1.3s / 3回目 1.7s
- 詳細遷移: 約2.2s
- 検索結果UI自体は正しく表示される

## ユーザー要求事項
1. **R1**: 同一検索クエリの再実行は、結果表示まで **0.5秒以内** であること
2. **R2**: 検索入力中、結果待ちであることが **即座に** 伝わること（空白のまま固まって見えない）
3. **R3**: `/api/works` はキャッシュ可能であること（同一クエリのサーバー/CDN再取得を減らす）
4. **R4**: 入力中の古い検索リクエストは破棄され、最新クエリの結果だけが表示されること（既存のレース対策を維持しつつ強化）
