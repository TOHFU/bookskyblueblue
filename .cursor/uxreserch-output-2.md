## 📋 人間中心設計（HCD）プロセス改善レポート

### 1. 利用状況の把握（Before）
- 検索結果→詳細の遷移が約 **2045ms**（ループ1計測）
- 詳細ページがサーバー `findById` を毎回待ち、検索結果の Work を捨てていた
- 遷移中は空白に見えやすかった

### 2. ユーザー要求事項
1. **R1**: 検索結果から詳細へ、カード表示まで **≤500ms**
2. **R2**: 検索結果に含まれる作品は、サーバー再取得を待たずに詳細を表示できること

### 3. 設計による解決策（実装内容）
- `stashSearchDetailWork` / `takeSearchDetailWork` で詳細用 Work を sessionStorage に受け渡し
- 詳細ページをクライアント優先表示に変更（API はフォールバック）
- `useLayoutEffect` で初回ペイント前にキャッシュを反映
- 先頭5件の詳細ルートを `router.prefetch`
- 詳細カードのフェードを短縮／キャッシュ表示時は省略

### 4. 設計の評価結果（After）
- `detailNavMs` ≈ **152–250ms**（Before 2045ms）→ **R1 合格**
- 検索結果クリック時は session キャッシュで即時カード表示 → **R2 合格**
